# מיזם שידוכים — כלים (שני דפים)

**Live:** <https://leeskies.github.io/datelink/> · `https://leeskies.github.io/datelink/export/`

שני דפים פשוטים בסגנון דף הנחיתה של מיזם השידוכים (אותו רקע, Rubik, כחול), RTL מלא.
אין צורך בשרת — נפתחים ישירות מ-`file://`.

## דפים — נקודות קצה (מוכן ל-GitHub Pages)
- `/` → `index.html` — יצירת קישור אישי
- `/export` → `export/index.html` — המרת CSV לכרטיסים
- `export.html` (שורש) — הפניה אוטומטית ל-`/export/` (תאימות לאחור)
- אין קישורים הדדיים בין הדפים.

## דף 1 — `/` (יצירת קישור אישי)
- שדות: **שם מלא** + **מספר פלאפון**
- כפתור **"העתק קישור"** — בונה קישור לטופס Google Forms עם מילוי
  אוטומטי של שני השדות האחרונים בטופס (`שם מלא`, `מספר פלאפון`) ומעתיק אותו.
- חיווי הצלחה פשוט (טוסט "✓ הקישור הועתק!").
- קונפיגורציה בראש `app.js` (`CONFIG`): כתובת הטופס וה-entry IDs.

## דף 2 — `/export` (המרת CSV לכרטיסים)
- טוענים את קובץ ה-CSV (ייצוא תשובות מ-Google Sheets) — בחירת קובץ, גרירה, או הדבקה.
- מציג קרוסלה פשוטה של הכרטיסים: **אין** מעבר אוטומטי; כפתורי חצים משני צידי
  המונה (◀ הבא משמאל, ▶ הקודם מימין — לפי RTL) וגם חצים במקלדת.
- **C** (או ב׳ במקלדת עברית) — העתקת הכרטיס הנוכחי.
- כפתור **"העתק כרטיס נוכחי"**, **"העתק את כל הכרטיסים"** ו**"הורד קובץ txt"**.
- הכרטיס מוצג על רקע עדין וצל רך (ללא מסגרת), מתחת לשורת הניווט.
- ריווח: שורה ריקה אחת בין שדה לשדה, **3 שורות ריקות בין כרטיס לכרטיס**.

### מיפוי עמודות (טופס → כרטיס)
| שאלה בטופס | עמודה ב-CSV | בכרטיס |
|---|---|---|
| שם + שם משפחה | שם + שם משפחה | שורת הכותרת ✨ |
| גיל / סטטוס / רמה דתית | זהה | שורות מקוצרות |
| עדה , רקע משפחתי | עדה , רקע משפחתי | 👳🏻 (שם השאלה כולל פסיק — מטופל) |
| מגורים / עיסוק / קצת עלי | זהה | 🏡 🎓 🧍‍♂️ |
| מה אני מחפש+ טווח גילאים | זהה | מפוצל ל-🎯 + "טווח גילאים" |
| מספר פלאפון לברורים ויצירת קשר | זהה | ☎️ |
| — (אין שאלת גובה בטופס) | — | השורה מושמטת; אם תתווסף שאלה — יופיע אוטומטית |
| שם מלא / מספר פלאפון / צירוף תמונה / הגעתי דרך / חותמת זמן | זהה | לא מופיעים בכרטיס (פרטיים) |

- תאים ריקים → השורה מושמטת מהכרטיס.
- שורות ללא שם → מדולגות (מסופר למשתמש).
- עמודות שלא זוהו → מוצגת אזהרה מתחת לסטטוס.

## הערות
- קישור ה-prefill: `?usp=pp_url&entry.1659420434=<שם>&entry.632618070=<טלפון>`
  (entry IDs מתוך קובץ ה-HTML של הטופס — השדות האחרונים: שם מלא, מספר פלאפון).
- חלוקת "מה אני מחפש + טווח גילאים": אם הטקסט כולל "טווח גילאים" או טווח מספרי
  בסוף (למשל "בת 22-27") — מפוצל לשתי שורות. אחרת מוצג כולו תחת 🎯.
- הטופס דרש התחברות לגוגל כדי לצפות בו — אם גם מגישים נתקלים בכך, כדאי לבדוק
  את הגדרות הטופס (ייתכן שהוא מוגבל לארגון/איסוף מיילים).
- אירוח ב-GitHub Pages: דוחסים את התיקייה ופורסים — `/` ו-`/export` עובדים מיד
  (הנתיבים יחסיים, אין תלות בשורש האתר).


## 📷 תמונות בכרטיסים — ישירות מהקישורים שבגיליון (ללא סקריפטים)

שאלת העלאת התמונות שומרת בגיליון התשובות **קישור Drive מלא** (למשל
`https://drive.google.com/open?id=...`). לכן אין צורך בסקריפט, בהרשאות או
בפריסה: `/export` שולף את הקישורים מעמודת "צירוף תמונה" בקובץ ה-CSV,
ולכל כרטיס מציג שני כפתורים — **פתח תמונה** (בכרטיסייה חדשה) ו-
**הורד תמונה** — ומצרף קישורים לקבצים המקוריים להורדת ה-txt.

### איך זה עובד
1. מורידים את ה-CSV מהגיליון (File → Download → CSV) — כפי שעושים היום.
2. טוענים אותו ב-`/export` (גרירה, בחירת קובץ או הדבקה).
3. הכרטיסים מופיעים עם כפתורי פתיחה/הורדה לכל תמונה.
4. הורדת ה-txt כוללת גם קישורי תמונה לכל כרטיס.

### גישה לתמונות (פרטיות)
- התמונה נטענת בדפדפן **של מי שחתום לחשבון Google שיש לו גישה לקובץ**.
  מי שאין לו גישה — פשוט לא רואה את התמונה (ללא שגיאה).
- חשבון **הבעלים** של הגיליון/הטופס: יש לו גישה — יראה הכל.
- **השותף/ית**: כדי שגם היא תראה תמונות, בעל התיקייה צריך להוסיף את
  המייל שלה לשיתוף התיקייה (עיין) — פעולה ידנית חד-פעמית ב-Drive.
- עמודות פרטיות ("מספר טלפון אישי", "שם מלא") אינן מופיעות בכרטיסים כלל.

### עמדת הכרטיס נשמרת
העמוד הנוכחי ומיקום הכרטיס נשמרים בדפדפן (localStorage): רענון או סגירת
לשונית חוזרים לאותו מקום אוטומטית.
